Распределение проблем по категориям

Как это устроено

Каждый инцидент за выбранный период автоматически относится к одной из групп проблем, если его название совпадает с настроенным паттерном. Группы и паттерны настраиваются администратором на вкладке «Настройка аналитики». Инциденты, не подошедшие ни под одну группу, попадают в категорию «Не классифицировано».

Популярные проблемы: у кого чаще

Разверните группу, чтобы увидеть паттерны, а паттерн — чтобы увидеть конкретные инциденты, которые под него попали.

Параметры расчета SLA

Порог длительности: сек.

Инциденты короче этого времени считаются сетевым/VPN-сбоем. Значение применяется сразу ко всем сохранённым инцидентам, повторная синхронизация не требуется.

Укажите через запятую группы хостов, которые нужно игнорировать при автоматической привязке по группам (шаблоны, общие группы ОС и т.д.).

Фильтрация триггеров (Исключение из SLA)

Вы можете отключить определенные типы триггеров (например, высокая загрузка диска/CPU), чтобы они не считались простоем и не уменьшали общий SLA доступности.

ТВ-панель (NOC-дашборд)

Страница /tv для вывода на телевизор: общая доступность, топ проблемных хостов по суммарному простою и проблемные клиенты. Обновляется автоматически. Доступ по токену — без входа в систему.

Параметры URL: ?period=today|7d|30d|month (период), ?refresh=60 (сек), ?top=20 (размер топа)

Новая группа проблем

Группа — это тип проблемы для BI-аналитики (например, «Проблемы с диском», «Сетевые сбои», «Проблемы 1С/SQL»). После создания группы добавьте к ней один или несколько паттернов — подстрок, по которым инциденты будут автоматически попадать в эту группу.
